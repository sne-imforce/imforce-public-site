# IMFORCE frontend

React, TypeScript, and Vite application for the public IMFORCE recruitment site and staff vacancy dashboard.

Copy `.env.example` to `.env.local` and set `VITE_API_BASE_URL` to the API server origin. See the [project setup guide](../README.md) for Supabase configuration, database migration, staff provisioning, and local development.

Run `npm install`, `npm run dev`, `npm run build`, or `npm run lint` from this directory.
